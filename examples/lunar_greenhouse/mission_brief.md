# Lunar Greenhouse: fictional mission brief

This character, setting, and project are invented solely for a documentation demo.

Mira is designing a small greenhouse in an imaginary lunar settlement. Plan a
layout with seed trays, grow lights, a water reservoir, and a robot watering cart.
Leave a clear path for the cart and choose a place to store spare tools.

Create a setup plan that covers layout, assembly, and a trial watering cycle.
Include a materials checklist. This is a creative exercise, not engineering
guidance for a real space mission.
